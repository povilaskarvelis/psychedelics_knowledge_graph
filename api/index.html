API

Query the Psychedelics Knowledge Graph and retrieve structured research data.

Using the API

No API key is required. The service is public and read-only. It provides papers, concepts, externally identified authors, and paper-level relationships. Searches can be filtered by paper type, subtype, author, concept, domain, relationship type, or year.

ORCID is used as the author ID when available, including across split OpenAlex profiles. Otherwise, the OpenAlex profile ID is retained. Unresolved name-only records are left out instead of being merged speculatively, as are profiles carrying conflicting ORCID evidence.

Base URL https://psychedelics-kg-api.onrender.com/api/v1
Find a concept ID 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/concepts/search?q=psilocybin&limit=5"
Search papers 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/papers/query" \
  -H "Content-Type: application/json" \
  -d '{
    "filters": {
      "concept_ids": ["compound:psilocybin"],
      "paper_types": ["primary_study"],
      "domains": ["clinical_outcome"]
    },
    "limit": 25
  }'

AI agents

AI agents can connect through Model Context Protocol (MCP), a standard way for them to use external tools. Give an MCP-compatible agent the URL below. No login is required because every available operation is read-only.

Machine-readable guide
MCP server https://psychedelics-kg-api.onrender.com/mcp
Typical client configuration 
{
  "mcpServers": {
    "psychedelics-knowledge-graph": {
      "url": "https://psychedelics-kg-api.onrender.com/mcp"
    }
  }
}

Use your client’s own field names if they differ.

Available tools

  • get_release_infoCurrent version, scope, and record counts
  • list_available_filtersSee valid categories and values
  • search_conceptsResolve labels and aliases
  • get_conceptInspect one standardized concept
  • search_authorsFind externally identified authors and name variants
  • get_author_papersRetrieve papers linked to an author
  • search_papersFilter and paginate the literature catalogue
  • get_paperLook up one paper or DOI
  • find_relationshipsSearch paper-level concept relationships
