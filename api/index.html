API

Psychedelics Knowledge Graph offers programmatic access through a public REST API and an MCP server for AI agents.

Using the API

The API provides access to the public Psychedelics Knowledge Graph catalogue, including papers, concepts, externally identified authors, and paper-level relationships. Searches can be filtered by paper type, subtype, author, concept, relationship-scoped subject or object kind, domain, relationship type, or year. Website graph categories are also published as reproducible filter presets, without limiting the API to those views. No API key is required.

Endpoint definitions, schemas, and examples are available in the API reference.

API reference OpenAPI specification
Base URL https://psychedelics-kg-api.onrender.com/api/v1

Examples

Find a concept ID 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/concepts/search?q=psilocybin&limit=5"
Search papers 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/papers/query" \
  -H "Content-Type: application/json" \
  -d '{
    "filters": {
      "concept_ids": ["compound:psilocybin"],
      "paper_types": ["primary_study"],
      "domains": ["clinical_outcome"]
    },
    "limit": 25
  }'

Valid controlled filter values are available from GET /api/v1/facets.

MCP for AI agents

The MCP server exposes public graph data as tools for compatible AI agents. Connect using the hosted server URL below. No authentication is required.

MCP server https://psychedelics-kg-api.onrender.com/mcp
Example client configuration 
{
  "mcpServers": {
    "psychedelics-knowledge-graph": {
      "url": "https://psychedelics-kg-api.onrender.com/mcp"
    }
  }
}

Tool overview

  • get_release_infoCurrent version, scope, and record counts
  • list_available_filtersSee valid categories and values
  • search_conceptsResolve labels and aliases
  • get_conceptInspect one standardized concept
  • search_authorsFind externally identified authors and name variants
  • get_author_papersRetrieve papers linked to an author
  • search_papersFilter and paginate the literature catalogue
  • get_paperLook up one paper or DOI
  • find_relationshipsSearch paper-level concept relationships
