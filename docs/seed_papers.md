# Seed Papers (Mechanistic Targets)

This is an initial list of candidate sources to seed the claims dataset.
Each paper should yield one or more binding/functional claims with provenance.

## Review sources with binding tables (open access)
- Schmitz and Roth, 2023, American Journal of Physiology-Cell Physiology
  - "G protein-coupled receptors as targets for transformative neuropsychiatric
    therapeutics"
  - Contains Ki values (from PDSP) for LSD, psilocin, psilocybin at 5-HT1A/5-HT2A
  - DOI: 10.1152/ajpcell.00397.2022

- Sessa et al., 2023, Psychedelic Medicine
  - "Methylenedioxymethamphetamine (MDMA): History, Neurobiology, and
    Therapeutic Potential"
  - Table includes DAT/NET/SERT inhibition IC50 values
  - DOI: 10.1089/psymed.2023.0015

- Nichols, 2016, Pharmacological Reviews
  - "Psychedelics"
  - Table includes mescaline Ki values (5-HT2A/5-HT2C)
  - Text includes DMT 5-HT1A Ki value (Deliganis et al. 1991)
  - DOI: 10.1124/pr.115.011478

## Primary mechanistic sources
- Halberstadt et al., 2012, Psychopharmacology (Berl.)
  - "Behavioral effects of α,α,β,β-tetradeutero-5-MeO-DMT in rats: comparison
    with 5-MeO-DMT administered in combination with a monoamine oxidase
    inhibitor"
  - Table 1 includes 5-MeO-DMT Ki values for 5-HT1A, 5-HT2A, 5-HT2C
  - DOI: 10.1007/s00213-011-2616-6

- Deliganis et al., 1991
  - "Differential interactions of DMT with 5-HT1A and 5-HT2 receptors"
  - PubMed ID: 1828347

- Ketamine: "Norketamine is a noncompetitive antagonist at the NMDA receptor"
  - DOI: 10.1016/S0014-2999(97)01116-3
  - PubMed ID: 9311667
