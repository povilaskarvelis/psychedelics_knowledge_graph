Applications and scripts

REST API

Interactive docs OpenAPI JSON Release metadata

No API key is required. The service is public and read-only. Start by resolving a human label to a canonical entity ID, then use that ID for repeatable evidence queries.

Base URL https://psychedelics-kg-api.onrender.com/api/v1
1. Resolve an entity 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/entities/search?q=psilocybin&limit=5"
2. Query evidence 
curl -sS \
  "https://psychedelics-kg-api.onrender.com/api/v1/findings/query" \
  -H "Content-Type: application/json" \
  -d '{
    "filters": {
      "compound_ids": ["compound:psilocybin"],
      "literature_sources": ["primary"]
    },
    "scope": "all_normalized",
    "detail_level": "summary",
    "limit": 25
  }'

AI agents

Model Context Protocol

Verified with MCP SDK 1.26

Connect any client that supports remote Streamable HTTP MCP. Client configuration formats differ, but the server URL is always the same. Authentication is not required because every exposed operation is read-only.

MCP server https://psychedelics-kg-api.onrender.com/mcp
Typical client configuration 
{
  "mcpServers": {
    "psychedelics-knowledge-graph": {
      "url": "https://psychedelics-kg-api.onrender.com/mcp"
    }
  }
}

Use your client’s own field names if they differ.

Use evidence responsibly

Interpretation rules

Keep evidence layers separate

Primary studies, meta-analyses, and reviews have distinct literature_source values. Do not merge them as independent studies.

Count studies, not rows

One paper can contribute multiple findings. Use study_count for evidence-volume comparisons.

Resolve canonical entities

Use entity search before repeated queries so aliases and spelling variants map consistently.

Return provenance

Include DOI, evidence location, result direction, and active release ID when supporting an answer.

Service availability

Public preview

The API currently runs on a free preview instance. After 15 minutes without traffic it may sleep, and the first request can take about a minute while the verified database reloads from object storage.
